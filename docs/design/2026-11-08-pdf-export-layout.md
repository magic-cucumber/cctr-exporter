# 题库 PDF 排版优化设计

日期 2026-11-08。用户已批准方案 1，实施与验证见[变更记录](../changes/2026-11-09-pdf-export-layout.md)。

## 当前实现与目标

桌面程序用浏览器分别截图题干和答案，再合并为一张题图。`TaskManager.kt` 按课程、章节、题型分组调用 `convertToPDF`，现有转换直接把图片交给 iText 排版，没有明确的缩放、编号、页码或标题规则。题图读取顺序依赖文件系统，转换失败也没有阻止成功打包。

本次改善电子阅读与 A4 打印：题目容易定位、正文清晰、分页完整、版式克制。沿用现有截图和 iText 8.0.4，不改变采集、登录、答案内容或导出目录结构。截图中的公式、图表与答案标记保持原样；正文仍为图片，不承诺题干全文搜索。

## 方案与选择

1. **建议：保留题图，完善 PDF 版面。** 增加标题、分组信息、题号、书签、页码与明确分页；改动集中，保留现有公式和图表兼容性。
2. 重建可搜索的文字 PDF。需要解析题干 HTML、公式与图片，可能改变现有复杂题型渲染，超出这次格式优化的合理范围。

用户确认按方案 1 实施。

## 可审阅的版式

- 纸张：A4 纵向，左右约 15mm 留白，预留独立页眉和页脚区域。
- 首页：小字“题库导出”、课程名、章节名、题型与总题数，不额外浪费一张纯封面。
- 正文：每题上方“第 1 题”及原题 ID；题图等比适配可用宽度；题间留白和细灰线。蓝灰标题与灰色辅助文字适合阅读和黑白打印。
- 短题：页尾空间不足时整题移到下一页，题号与题图保持一起。
- 超长题：保持正文比例分多页，优先在空白行分页，后续页注明续题。有足够空间时接在上一题后。没有适合空白的连续长图采用连续分段，保留内容区的全部像素。
- 页眉：课程与章节；过长名称按实际可用宽度处理，避免与正文重叠。
- 页脚：以 `1 / 5` 显示当前页与总页数。
- 导航：每题一个 PDF 书签，可直接跳到对应题号。
- 顺序：按原题 ID 文件名自然排序，数字 2 在数字 10 前；题号在每份 PDF 内连续。

## 数据与失败处理

课程名、章节名、题型来自现有文件层级，由调用方明确传入；旧调用保留默认参数兼容。空列表或坏图明确返回失败；调用方检查转换结果，使当前导出任务失败并显示错误，不再把无效 PDF 当作成功成果。

## 实施与验证

1. 建立离线代表性图片：短题、包含图表的题、宽图、有空白行超长题、无空白行超长题；输入文件名故意乱序。
2. 验证 PDF 的 A4 尺寸、自然顺序、题号和书签、页码、超长题分段完整性、空列表与坏图失败。
3. 编译实际项目；不调用真实账号或远程题库。
4. 将 PDF 渲染为 PNG，检查首页、普通页、续题页及末页的对齐、清晰度、中文显示和留白。
5. 结果归档到 `docs/changes/2026-11-09-pdf-export-layout.md`。样例与临时验证文件放在 `build/` 下。
