# 题库 PDF 正文可复制诊断与方案

2026-11-09。诊断与实施建议，尚未修改导出代码。

## 已确认的原因

实物抽查覆盖 4 份 PDF 的首页及代表性题目。A4 页面、思源黑体和书签证明新版外层排版已生效。题图区域提取不到文字。代表性题图宽约 734 像素，排入约 511pt，等效约 103 DPI。抽查可见细笔画、黑字彩边、正确选项整行变红、多数选项没有 A/B/C/D，题块之间约 46pt 空隙。抽查内容可阅读，未观察到随机换字或缺字。该结论限于已查看的样本与页面。

源码解释了正文为何仍像旧版。题目接口解码后能提供 `Question.subjectHtml`、`Option.html` 与 `Option.isTrue`。旧管线在区分 PDF 和 IMG 前，逐次用 Edge 截图题干、选项或答文，选择题在正确选项前加入红色 `√`，再合成每题的 PNG。PDF 排版器收到的只有 PNG 文件，因此只把题号、标题和页脚写成文字，题图仍是像素。源码位置见 `question-list.kt:52`、`DriverUtil.kt:28`、`TaskManager.kt:146`、`TaskManager.kt:218`、`PdfExport.kt:135`。

仓库内示例解码后，题干与答案包含普通 HTML 段落及共 15 个 SVG 数据 URI 公式。其中 11 个 SVG 含内嵌 `@font-face`，全部没有 `alt`。抽取纯文本会漏公式。直接把 SVG 内的字符拼起来也会丢失上下标、分数和符号的位置。现有临时 HTML 没有显式声明 UTF-8。若另有确实换字的样本，先对照解码后的文本、浏览器 `document.characterSet`、DOM 文本和最终渲染，区分源内容、编码与字体问题。

## 推荐实现

1. 在截图前分流 PDF。按原课程、章节、题型分组，将原始题目结构传给 PDF 渲染器，保留现有题序、书签、页眉页脚、A4 和 ZIP 目录。沿用原图导出流程。
2. 以 DOM 顺序提取段落和文本节点，用现有 iText `layout` 输出可搜索、可复制的正文。保留换行、列表、上下标和基本强调，使用经中文提取回归验证的嵌入字体。PNG/JPEG 直接嵌入，简单表格保留文本单元格和跨行跨列。对公式、自带字体的 SVG 或复杂表格，先验证原样矢量渲染。兼容性不足时用现有 Edge 仅渲染该局部，并保留原位置、大小比例和阅读顺序。资源加载失败应留下明确错误，避免无提示丢图。
3. 一题使用连续题号、简短题型和左对齐选项。保留上游已有的 A/B 等标签及顺序，确实缺少标签时按经验证的选项顺序生成。当前 `Option` 只读取 `istrue` 和 HTML，JSON 对象读取时还丢弃了键，需用脱敏真实题确认标签或 ID 是否另有来源。单选和多选都按 `istrue == 1` 映射，另列可复制的“参考答案 B、D”。判断题沿用“正确／错误”语义，主观题优先渲染 `answerhtml_svg`，缺失时使用平台原文，未提供则明确标注。

现有 Selenium 4.20 可通过 Edge headless 打印结构化 HTML。按每个课程／章节／题型组构建统一打印页，可较快验证正文可复制和复杂公式保真。标题层级、分页、字体等待、书签及页码要用实际支持的 Edge 版本验证，必要时由 iText 后处理。CDP 的 `generateDocumentOutline` 属于实验参数。直接使用 iText 负责正文分页、书签和页码控制更稳定，Edge 可专注于复杂块。项目已带 Jsoup、iText layout/svg 和 Selenium，当前构建未带 pdfHTML 转换器。参考 [Selenium 打印文档](https://www.selenium.dev/documentation/webdriver/interactions/windows/#print-page)和 [Chromium 打印协议](https://chromedevtools.github.io/devtools-protocol/tot/Page/#method-printToPDF)。

## 验收

- 使用脱敏真题覆盖单选、多选、判断、主观、图表、嵌入字体的 SVG 公式及长题跨页。以原平台核对选项顺序、标签、全部正确选项、答案及图表公式，无空白资源或漏题。
- 从输出文件直接查找并复制中文题干、选项和答案，核对内容、标点和顺序。用 PDF 文本解析器验证相同结果，特别覆盖中文异体映射和公式前后的文字。没有文本语义的公式或图片可保留为图，正文仍可选中。
- 逐页渲染抽查普通页、跨页及宽图或宽表页面，核对可读字号、题号与正文不分离、页码与书签准确，课程／章节／题型 ZIP 结构与图片导出回归正常。
