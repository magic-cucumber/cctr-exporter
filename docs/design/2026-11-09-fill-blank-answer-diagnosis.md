# 填空题参考答案错位诊断

2026-11-09。记录问题证据和建议方案，产品代码尚未修改。

## 已验证的原因

- 实物审查线程检查了 `task_65` 的三份填空题 PDF，共 11 页、41 题。41 题均把内容排成带字母的选项，并在参考答案区显示“平台未提供”，其中 26 题有多条误排条目。该结果确认导出表现，不能确定源数据如何划分空位或同义答案。
- `TaskManager.kt:150` 按接口的 `questiontypename` 分组，`:154` 把 `Question` 原样交给可复制 PDF 导出器。
- `question-list.kt:52` 保留题型名称、`subjecthtml_svg`、`answerhtml_svg`、`answer` 及原始 `options`。`:71` 的 `hasOptions` 只根据 `options` 是否为数组或对象判断，无法区分选择项和填空答案。`:77` 将数组或对象中的条目解析成 `Option`，对象键保留在 `sourceKey`；`:104` 的 `isTrue` 只表示 `istrue == 1`。DTO 没有空位编号或同义答案字段。
- `SelectableQuestionPdf.kt:94` 正常输出题干。`:96` 以后把任何非空 `options` 都当作选择题，追加字母编号，并仅用 `isTrue` 为真的字母组成参考答案。未收集到真值就显示“平台未提供”。`:117` 的独立 HTML／原文答案只在 `options` 为空时读取，导致非空填空答案字段被跳过。
- 用现有便携包内的 Java 和应用 JAR 执行三道合成填空题，未调用平台。非空 `options` 且 `istrue=0` 的题错误地出现 A/B 和“平台未提供”，两个独立答案字段均未输出；`istrue=1` 时错误地显示“参考答案：A”；空数组时独立 HTML 答文正常。复现产物位于 `build/selectable-pdf-validation/fill-blank-diagnosis/`。
- 旧 IMG 流程在 `TaskManager.kt:179` 也按 `hasOptions` 选择截图内容，但不会自行生成 A/B 字母标签或字母答案行。此次建议只修复 PDF 的填空题路由。

## 建议修复

1. 在处理通用选项前识别已确认的填空题类型，保留原题干和所有空格。当前仓库仅记录一个 `cname=填空题、number=4` 的题型元数据示例，且 `Question` 尚未解析 `questiontypenumber`。可先以实际出现并核实的精确题型名匹配；如有稳定的题型类别字段，再按脱敏载荷验证后使用。不要以是否存在 `options` 或单个题型 ID 推断题型，也不要用宽泛子串误分选词填空等其它类型。
2. 在“参考答案”区优先渲染非空的 `answerhtml_svg`，保留其中的公式和图；其次采用平台 `answer` 原文。用 DOM 判断 HTML 答文有可见内容，空标签、空白或仅不换行空格不应阻止兜底，只有公式或图的答文仍有效。两者均缺省时，按已证实的填空 `options` 结构输出答案正文。当前证据不足以把选择题 `istrue` 规则用于过滤填空答案，保留来源中有依据的答案内容，不将其写进题干，也不生成 A/B 标签。
3. 用真实脱敏响应核对多空的位号、排序、同义答案分组及 `istrue` 语义，再决定是否逐空标号、以“或”连接同义项。PDF 中可见的行、数字对象键、候选数量和下划线数量都不能单独证明空位结构。没有分组证据时可按源顺序列出确认属于答案的内容，不给各项虚构空位或关系。确实没有可用答案时再提示“平台未提供”。

## 验收

- 让已有合成复现改为题干后无 A/B，独立答文在参考答案区，覆盖 HTML／原文／两者缺省、有无 `istrue`、空数组和空对象。题干空格、符号、顺序、可复制性保持。
- 以脱敏真实响应补单空、多空、同义选项和无答文仅有 `options` 的样例。以平台答案为对照，核对各空顺序、候选完整性、公式及文本复制。真实空位载荷尚未核实前，不宣称多空／同义项映射正确。
- 回归单选、多选、判断、主观、题号书签和原分组。相关 PDF 重新渲染抽查，并对比文本提取内容。
